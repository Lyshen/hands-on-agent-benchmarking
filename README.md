# hands-on-agent-benchmarking

**Build · Break · Benchmark**

Building AI Agent Harnesses from first principles and benchmarking agents on real-world tasks, one concept at a time.

## About

This is my personal, hands-on exploration of AI Agent Harnesses and benchmarking.

I'm building my own Agent Harness from scratch in Go, one concept at a time, to understand how agents actually work under the hood.

The journey covers the building blocks of agent systems — from model interactions and tool calling to agent loops, context management, memory, planning, sandboxed execution, and beyond.

But building the harness is only half of the journey.

The other half is **benchmarking**: putting agents through real tasks, experimenting with different harness designs and capabilities, comparing approaches, and understanding what actually improves performance.

I'm especially interested in how harness design affects task completion, reliability, efficiency, and cost — and what we can learn from failures.

The goal isn't just to build an agent that works. It's to understand **why it works, where it fails, and how to measure the difference**.

## What I'm Exploring

- **Building from scratch:** Understanding and implementing the core concepts behind Agent Harnesses.
- **Harness engineering:** Exploring tool execution, sandboxing, context management, memory, planning, and other agent capabilities.
- **Hands-on benchmarking:** Running agents against existing benchmarks and realistic tasks, with reproducible experiments.
- **Comparative evaluation:** Studying how models, harness designs, and execution strategies affect outcomes.
- **Failure analysis:** Investigating why agents succeed or fail, and using benchmark results to guide improvements.
- **Cost and efficiency:** Looking beyond success rates to understand the resources required to get work done.

This is an ongoing learning and experimentation project, not a production-ready agent framework.

## AIAgentBenchmark.com

This project is part of my broader exploration at **[AIAgentBenchmark.com](https://aiagentbenchmark.com/)**.

AIAgentBenchmark.com is dedicated to **Benchmarking Real Work** — understanding how AI agents perform on meaningful tasks through benchmark resources, practical guides, and hands-on evaluations.

I believe a benchmark should tell us more than who's at the top of a leaderboard. It should help us understand what agents can actually accomplish, their limitations, the cost of getting work done, and how much confidence we can place in their results.

This repository is where I explore those questions from the engineering side — by building Agent Harnesses myself and putting them to the test.
